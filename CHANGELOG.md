# Changelog

## 0.1.0-rc.1 — 2026-09-09

- First public release candidate.
- Navigate visible tracks, library rows, and action menus with Vim-style keys.
- Add an explicit `Alt+Shift+V` enable/disable toggle.
- Use an original non-branded extension icon.
- Remove the experimental in-page arrow-key volume/transport controls.
- Restrict selection to track rows and rediscover rerendered rows by stable identity.
- Support Spotify's current grid-cell play controls as well as its older test-id markup.
- Add wrapping action navigation, reliable menu focus/closing, playlist search, and origin restoration.
- Protect editable and native interactive controls from extension shortcuts.
- Replace menu polling with mutation-driven menu detection.
- Move injected presentation rules to a packaged stylesheet.
- Add fixture-backed browser tests, CI validation, security guidance, and store promotional artwork.
